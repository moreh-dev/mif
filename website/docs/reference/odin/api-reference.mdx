Odin serves models on Kubernetes through four custom resources in the `odin.moreh.io/v1alpha1` API group. `InferenceService` (namespaced) is a running inference deployment. `InferenceServiceTemplate` (namespaced) and `ClusterInferenceServiceTemplate` (cluster-scoped) are reusable spec fragments that an `InferenceService` can reference. `RuntimeBase` (cluster-scoped) carries the engine-level defaults that sit underneath them.

## InferenceService

An `InferenceService` describes a model deployment — the inference engine, the model, parallelism, and the pod templates that run it. The pod templates (`template`, `workerTemplate`) are standard Kubernetes [`PodTemplateSpec`](https://kubernetes.io/docs/reference/generated/kubernetes-api/v1.32/#podtemplatespec-v1-core) objects.

## ClusterInferenceServiceTemplate

A `ClusterInferenceServiceTemplate` is the cluster-scoped form of `InferenceServiceTemplate`: one template that `InferenceService` resources in any namespace can share. An `InferenceService` references it through `spec.templateRefs`. When a reference omits `kind`, it resolves to the `ClusterInferenceServiceTemplate` of that name when one exists, and to the namespaced `InferenceServiceTemplate` otherwise. The pod templates (`template`, `workerTemplate`) are standard Kubernetes [`PodTemplateSpec`](https://kubernetes.io/docs/reference/generated/kubernetes-api/v1.32/#podtemplatespec-v1-core) objects.

## RuntimeBase

A `RuntimeBase` is a cluster-scoped set of engine-level defaults maintained by a platform administrator. An `InferenceService` selects one through `spec.runtimeBaseRef`, and the selected fields form the lowest-priority layer of the rendered spec, so any referenced template and the `InferenceService` itself override them. Across an `InferenceService` and the templates it references, `runtimeBaseRef` may be declared in at most one place, and a `RuntimeBase` cannot select another one. The pod templates (`template`, `workerTemplate`) are standard Kubernetes [`PodTemplateSpec`](https://kubernetes.io/docs/reference/generated/kubernetes-api/v1.32/#podtemplatespec-v1-core) objects.
